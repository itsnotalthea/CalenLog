# CalenLog

> Track habits and routines over time.

## Features

- **Tap to log** — click a day on the calendar to cycle a habit's intensity, then click again to clear it.
- **Customizable** — rename and recolor habits (with color wheel), and switch the whole interface between light and dark mode.
- **Password protected** — your data is locked behind a password of your choosing.

## Why Flutter

CalenLog was initially meant to ship as an Electron app. But Electron was far too heavy for a small productivity app. So the app was written in Flutter instead. It has one native binary per platform, which is a much smaller footprint, and the same UI on Windows and macOS.
